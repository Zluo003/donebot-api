# DoneBot 模型定价

DoneBot 的 LLM 按“渠道价格 × 每模型倍率”计费。管理页每个 LLM 只编辑一个倍率，输入、输出和缓存基础单价由渠道维护；图片、音频和视频继续按模型配置基础售价。配置复用现有分组价格与计费链路，用户专属倍率仍沿原链路生效，没有新增账本、报价单或预授权。

## 单位与配置

| 标签 | 可编辑项目 | 界面单位 | 实际计量 |
| --- | --- | --- | --- |
| LLM | 每模型倍率 | 倍 | 上游实际 token，使用渠道输入/输出/缓存价格 |
| 图片 | 每个模型 `1K` / `2K` / `4K` | USD/张 | 实际产出张数及尺寸；模型只使用其支持档位 |
| 音频 / Suno | `v6` / `v6-wild` / `v6-mini` / `custom-model` | USD/次 | 每次生成；`max_mode=true` 为两单位 |
| 音频 / TTS | `tts` | USD/百万 Unicode 字符 | 实际输入字符数 |
| 视频 / Seedance | 每个模型、官方分辨率、有/无参考视频 | USD/输出秒 | 成功任务实际输出时长 |

从 v0.4.0 升级时，已有 LLM 自定义单价会暂时保留计费，避免升级直接改价。请核对渠道价格与各模型倍率，并在 DoneBot 的 LLM 页点击一次“保存”，将旧单价切换为渠道价 × 模型倍率。

LLM 倍率为非负有限数，`0` 表示免费；没有单独设置时沿用现有分组倍率，新分组默认为 `1`。缺少渠道定价的模型可以保存倍率，但不能开启，页面提示“请先配置渠道价格”。DoneBot 不编辑或提交 LLM token 单价。

模型目录仅显示 DoneBot 分组已绑定的启用账号实际开启的模型。先添加并启用相应账号、绑定 DoneBot 分组并配置账号允许模型，再同步模型。无可用价格时不能启用，已启用模型仍可关闭。编辑好开关与倍率/价格后点击一次“保存”，后端校验全部配置后一次写入；校验失败不会只保存其中一部分，页面保留草稿。

音频和视频标签始终显示，功能未启用时仍可提前配置账号、模型与价格。`DONEBOT_FEATURES_AUDIO`、`DONEBOT_FEATURES_VIDEO` 控制实际模型调用，未启用时页面会显示状态提示。

媒体模型全部覆盖价格清空后，移除该模型的分组直接覆盖，恢复渠道默认价格。部分档位留空表示该档位未配置，不能调用，不逐档恢复渠道价。视频必须存在请求对应的分辨率和参考视频档位，不在档位之间回退。明确的零价可表示免费，空值表示未配置。

## 管理接口

`GET /api/v1/admin/donebot/{llm|images|audio|video}/models` 返回 `editable_pricing`、`pricing_configured`；视频另外返回 `video_resolutions`。LLM 的 `editable_pricing.rate_multiplier` 是当前可编辑倍率，`pricing_configured` 表示渠道是否存在可用基础价格。

管理页使用 `PUT /api/v1/admin/donebot/{kind}/configuration` 同时保存开关与定价。例如 LLM：

```json
{
  "models": [{
    "model": "gpt-test",
    "enabled": true,
    "pricing": {"rate_multiplier": 1.2}
  }]
}
```

LLM 的 `pricing` 只包含 `rate_multiplier`，不提交 `input_price`、`output_price`、`cache_write_price` 或 `cache_read_price`。不可用或缺少规格的条目只提交开关，省略 `pricing`。

媒体沿用各自的售价结构，例如视频：

```json
{
  "models": [{
    "model": "doubao-seedance-2-5-260628",
    "enabled": true,
    "pricing": {
      "video_prices": [
        {"resolution": "720p", "reference_video": false, "price_per_second": 0.1},
        {"resolution": "720p", "reference_video": true, "price_per_second": 0.15}
      ]
    }
  }]
}
```

图片使用 `image_prices`，Suno / TTS 使用 `tier_prices`。现有 `/models` 与 `/pricing` 管理接口保留，新的管理页通过 `/configuration` 一次保存。所有管理更新复用管理员权限与 step-up 校验。

APIMart 图片的实际尺寸、图层与异步结算细节见[接入说明](APIMart-接入说明.md)；Seedance 时长来源、自动时长估算与延长计量见[接入说明](Seedance-接入说明.md)。供应商原生费用字段不等于本地扣费，配置售价前须自行核对供应商成本及币种。本轮验证使用模拟上游，未执行真实付费生成。
