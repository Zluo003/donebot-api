# DoneBot 模型定价

DoneBot 管理页按模型填写最终基础售价，复用现有 `Group.ModelPricing` 价格卡，优先于渠道价格。底层保存时按现有分组倍率归一，显示时还原最终价；用户专属倍率仍沿原链路生效。无需在此额外维护一套公共倍率，也没有新增账本、报价单或预授权。

## 单位与配置

| 标签 | 价格项目 | 界面单位 | 实际计量 |
| --- | --- | --- | --- |
| LLM | 输入、输出、缓存写入、缓存读取 | USD/百万 token | 上游实际 token |
| 图片 | 每个模型 `1K` / `2K` / `4K` | USD/张 | 实际产出张数及尺寸；模型只使用其支持档位 |
| 音频 / Suno | `v6` / `v6-wild` / `v6-mini` / `custom-model` | USD/次 | 每次生成；`max_mode=true` 为两单位 |
| 音频 / TTS | `tts` | USD/百万 Unicode 字符 | 实际输入字符数 |
| 视频 / Seedance | 每个模型、官方分辨率、有/无参考视频 | USD/输出秒 | 成功任务实际输出时长 |

音频和视频标签分别受 `DONEBOT_FEATURES_AUDIO`、`DONEBOT_FEATURES_VIDEO` 控制。新增账号后同步模型，设置模型价格，再开启模型。候选模型可在首次定价前显示；无可用价格时不能启用。同步和保存模型开关不会覆盖尚未保存的价格草稿。

每个模型清空全部覆盖价格后，移除该模型的分组直接覆盖，恢复渠道默认价格。媒体模型部分档位留空表示该档位未配置，不能调用，不逐档恢复渠道价。视频必须存在请求对应的分辨率和参考视频档位，不在档位之间回退。明确的零价可表示免费，空值表示未配置。

## 管理接口

`GET /api/v1/admin/donebot/{llm|images|audio|video}/models` 返回 `editable_pricing`、`pricing_configured`；视频另外返回 `video_resolutions`。`PUT /api/v1/admin/donebot/{kind}/pricing` 按模型更新：

```json
{
  "models": [{
    "model": "doubao-seedance-2-5-260628",
    "pricing": {
      "video_prices": [
        {"resolution": "720p", "reference_video": false, "price_per_second": 0.1},
        {"resolution": "720p", "reference_video": true, "price_per_second": 0.15}
      ]
    }
  }]
}
```

LLM 接口中的 `input_price` / `output_price` / `cache_write_price` / `cache_read_price` 使用 USD/token，管理界面按百万倍换算。图片使用 `image_prices`，Suno / TTS 使用 `tier_prices`。所有管理更新复用管理员权限与 step-up 校验。

APIMart 图片的实际尺寸、图层与异步结算细节见[接入说明](APIMart-接入说明.md)；Seedance 时长来源、自动时长估算与延长计量见[接入说明](Seedance-接入说明.md)。供应商原生费用字段不等于本地扣费，配置售价前须自行核对供应商成本及币种。本轮验证使用模拟上游，未执行真实付费生成。
