## 修复与变更

- 修复调度缓存漏存账号媒体能力，导致配置正常的 APIMart 图片、音乐、TTS 账号被误判为不可用并返回 503。
- APIMart 图片、音乐、TTS 使用独立适配模块，各自校验参数、路径和结果；图片与音乐保持异步，TTS 保持流式。
- 后台新增三个独立账号配置入口。已有多能力账号、其它服务配置、别名、自定义映射与密钥保留。
- 明确尚未派发的选号失败记录为失败回执，避免客户端一直等待；已派发或结果不明的任务继续按原回执恢复，不自动重提。

## 部署说明

升级并重启后自动重建调度快照，无需清空 Redis，也无需重新创建现有账号。

历史未确认任务没有足够证据时，不会自动改判失败、退款或重新生成。此版本已通过本地隔离回归；生产部署与收费供应商生成由部署后验证。
