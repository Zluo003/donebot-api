# APIMart 独立适配与媒体调度修复

日期：2026-11-06。发布版本：`v0.4.10`。

## 故障与修复

已登录运维后台只读核查到 Seedream 请求在选择账号时返回 HTTP 503，错误为
`No eligible APIMart accounts`，没有向供应商提交。账号本身正常、调度开启、
绑定正确分组且显式配置了对应媒体能力。调度缓存投影遗漏 `openai_capabilities`，
导致缓存快照无法通过媒体能力准入。本次只补齐这个凭据字段，不放宽模型白名单、
隐私要求、分组或权限。启动的初始快照重建会刷新缓存，无需清理 Redis。

APIMart 图片、音乐和 TTS 分为独立适配模块，各自维护参数校验、原生路径、
模型限制和响应解析；共享低层安全传输。图片、音乐继续持久异步，TTS 返回音频流，
不预读全量音频。付费生成请求不自动重试。

管理后台分别提供“添加 APIMart 图片账号”“添加 APIMart 音乐账号”和
“添加 APIMart TTS 账号”。新账号只配置对应服务；旧多能力账号保留编辑标签页，
不自动拆分或迁移。未操作模型时，保留模型映射字段的缺失、空对象或原始值；
修改一类服务时保留其它服务、别名、自定义映射和未替换密钥。

选号失败且尚未预扣、尚未提交上游时，处理器设置可信内部标志，回执中间件仅在
HTTP 503、原状态未确认且没有任务或计费标志时将其记为失败。已有任务、已有计费
标志或其它结果不明的请求保持未确认；不凭错误文案决定退款。

## 隔离验证

后端定向验证：

```sh
cd backend
go test -tags unit ./internal/repository ./internal/server/middleware ./internal/handler ./internal/service -run 'TestScheduler.*(Media|Capabilities)|TestDoneBotMedia|TestDoneBotSpeech|TestAPIMart|TestSeedance' -count=1
```

四包通过。覆盖真实 miniredis 快照写入和读取、显式媒体能力、文本拒绝、模型白名单、
原生适配派发、别名、跨接口模型拒绝、上游零提交、TTS 返回前零读取、未派发失败
回执和已存在任务或计费标志保护。Repository 完整 unit 包亦通过。

资源清理与类型断言的静态检查修正后，TTS Handler、公开媒体目录和完整 Repository
unit 测试通过；最终适配器路径测试通过。CI 同版 `golangci-lint v2.14.0` 全量检查
报告 `0 issues`，未加入规则抑制。

前端账号弹窗、账号页与操作栏定向 Vitest 共 31 项、语言键完整性 3 项、ESLint、
类型检查及生产构建通过。弹窗含 14 项回归，涵盖三种独立创建入口、旧多能力账号、别名、自定义映射、
只改名称时原样保留映射，以及密钥留空保留行为。

客户端媒体验证独立在 DoneBot 仓库完成：9 个文件共 110 项测试通过，包含隔离网关
与两 Bot 原会话回执的端到端验证。503 无任务 ID 后恢复失败或恢复已存在任务的场景
均只发送原始付费 POST；未确认通知与最终回执分别去重。

## 部署与验证边界

用户自行部署 [v0.4.10](https://github.com/Zluo003/donebot-api/releases/tag/v0.4.10)，
重启后自动重建调度快照。本轮没有部署生产、保存后台账号配置或新建收费生成请求。
隔离测试不证明实际供应商生成和公网产物下载已经成功。

历史未确认回执缺少可信未派发证据，不能自动判失败、退款或重新提交。已有“生成
完成但产物取回失败”的历史任务仍应按原任务取回；客户端新增安全错误分类与延迟通知，
不将取回失败当作生成失败。
