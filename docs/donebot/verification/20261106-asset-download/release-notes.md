## 修复与变更

- 修复本地签名资产下载被管理前端拦截、返回 HTTP 200 HTML，导致 DoneBot 显示“图片已生成但文件取回失败”的问题。正常下载继续验证签名和有效期。
- 本地与 S3/R2 分别保存公网地址，后台切换存储方式时恢复各自配置，避免带入另一驱动的域名。空 S3 公网地址仍使用预签名链接。
- 保留旧 API 兼容及历史资产的原存储快照，切换新存储配置不会改变旧文件的读取位置。

## 部署说明

升级并重启网关即可生效，本轮无需更新 DoneBot 客户端。客户端会继续取回原任务结果，无需重新生成或重复付费。

旧文件不自动迁移，已失效或清理的文件不保证恢复。生成存储的本地目录是根目录，文件仍位于其 generated 子目录中；无需手工移动或放宽目录权限。
