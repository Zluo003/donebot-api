## 修复与变更

- 修复本地签名资产下载被管理前端拦截、返回 HTTP 200 HTML，导致 DoneBot 显示“图片已生成但文件取回失败”的问题。正常下载继续验证签名和有效期。
- 本地与 S3/R2 分别保存公网地址，后台切换存储方式时恢复各自配置，避免带入另一驱动的域名。空 S3 公网地址仍使用预签名链接。
- 保留旧 API 兼容及历史资产的原存储快照，切换新存储配置不会改变旧文件的读取位置。
- 媒体任务查询、回执与恢复保留脱敏后的具体错误原因、HTTP 状态、错误码和请求编号，便于客户端和 Bot 说明失败。凭据、供应商地址及请求正文不进入公开诊断。
- 依据内部派发边界识别明确未调用上游的错误；超时、连接中断等结果不明的任务继续核对原回执，不自动重新生成或冒充已退款。
- 升级 brotli 与 klauspost/compress，修复安全扫描发现的可达漏洞；限制回执通用标识字段夹带供应商 URL。

## 部署说明

存储隔离与下载路由修复在升级并重启网关后生效，客户端会继续取回原任务结果，无需重新生成或重复付费。完整的错误详情展示需要同时使用本轮更新的 DoneBot 客户端。

旧文件不自动迁移，已失效或清理的文件不保证恢复。生成存储的本地目录是根目录，文件仍位于其 generated 子目录中；无需手工移动或放宽目录权限。
