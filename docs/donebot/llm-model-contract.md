# DoneBot LLM 公开模型与上游映射

## 身份与能力

- 账号模型目录的 `id` 是网关对客户端公开的模型 ID。能力与思考等级按这个 ID 的登记或显式配置确定。
- 渠道、复合路由和账号的模型映射只确定上游路由与转发名称；上游可使用任意私有名称，不需要加入 DoneBot 模型别名表。
- 同一个公开模型可以由多个账号映射到不同上游名称。目录生成与请求准入不得通过比较这些名称判断它们是否是同一个公开模型，也不从上游名称推断另一个模型的能力。
- 上游名称仍参与实际路由和按模型配置的协议规则匹配；这不等同于以名称推断模型身份或能力。

启用开关不是跳过其它校验：公开目录仍要求有效分组、启用且可调度的 API 账号、明确映射、已配置价格以及兼容的原生接口。OAuth/订阅转 API 不因模型映射而开放。真实协议不兼容仍会阻止对应接口，不能靠改名绕过。

新模型接入时，分别完成公开 ID 的能力登记、原生接口支持、价格与分组授权，以及现有路由/账号中的上游映射。不要为了适配映射名称反复改客户端或扩充上游别名名单。
